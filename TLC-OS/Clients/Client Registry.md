# Client Registry

The client registry is the sorted list of client entries. Add entries using the
short form in the [Client Intake SOP](./SOPs/Client%20Intake%20SOP.md) and the
[Client Entry Template](./SOPs/Client%20Entry%20Template.md).

> **Privacy.** This repository publishes every document under `TLC-OS/`. Do not
> commit real customer names, phone numbers, email addresses, or street addresses
> here. Use the approved system of record for actual client data; this page defines
> the format and sort order only.

## Sort Rule

List every client by **last name, A to Z**, then by first name A to Z when two
clients share a last name. Compare case-insensitively.
