## Decision Status Definitions

- **CHALLENGE:** The requirement needs a source, owner, evidence, or smaller formulation.
- **DELETE:** Remove the element from the proposed process.
- **EXPERIMENTALLY REMOVE:** Remove it in a bounded, reversible test.
- **COMBINE:** Merge it with another element that serves the same outcome.
- **RETAIN:** Keep the smallest justified form.
- **RESTORE:** Add back a previously removed element because validation demonstrated a need.
- **SIMPLIFY:** Reduce complexity without removing the protected outcome.
- **ACCELERATE:** Reduce wait, queue, batch, handoff, or rework time.
- **AUTOMATE:** Automate only after the work survives prior steps.
- **REJECT AUTOMATION:** Do not automate because the work should be deleted, is unstable, or lacks sufficient value.
- **VERIFY BEFORE REMOVAL:** Obtain qualified confirmation before changing a potentially binding or safety-critical control.
